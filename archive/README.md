# Archive

Earlier designs, kept for reference. Nothing here is part of the current release, which is in `rev8_JonAirBoat/`. Older reports that are still useful are in `rev8_JonAirBoat/reports/archive/`.

| Folder | What it is |
|---|---|
| `rev0_StitchAndGlue/` | The first DIY Mini-Airboat: a custom aluminum hull with a Suzuki G13 drivetrain, with CAD, BOM, build guide and CNC DXFs. |
| `StraddleDart_rev7/` | The Straddle Dart: a 12.5 ft riveted-aluminum airboat with a Suzuki G13B belt redrive. The rev8 cage and the v1.0.0.2 drivetrain came from this design (in Onshape, "Airboat rev7"). |
| `rev8_JonAirBoat/` | The GSX-R1000 bike-engine stand and reduction note with its calc, replaced by the Rotax 800R E-TEC. |

The 16 ft and 18 ft hull explorations are not here; they live on the `rev8/1652-hull` and `rev8/1860-hull` git branches.
